# Plan: Baseline Automation Engine — `scraper.py` Browser Init + Cookie Consent

## Overview

Replace the `NotImplementedError` stub body of `scrape()` in `scraper.py` with a working
Playwright automation engine that:

1. Launches a stealth-configured Chromium browser context (realistic UA, 1280×800 viewport,
   sandbox flags disabled).
2. Applies `playwright-stealth` via `stealth_sync(context)` immediately after context
   creation to strip `navigator.webdriver` and all automated-driver fingerprints.
3. Navigates to `https://www.google.com/maps`.
4. Detects and dismisses Google's cookie/consent dialog ("Accept all") if present.
5. Waits until network is idle before returning control to the caller.

Scope is strictly the browser-init and consent-handling block. Result parsing, lead
extraction, and DB persistence are out of scope for this card.

## Architecture Decisions

### 1. Sync vs. async Playwright API

Use `sync_playwright` (already imported). The scraping pipeline is single-threaded and
driven by Streamlit; async would require an event loop wrapper with no benefit here. All
Playwright calls use the synchronous API throughout.

### 2. `stealth_sync` target: BrowserContext, not Page

`playwright_stealth.stealth_sync` accepts either a `Page` or a `BrowserContext`. Passing
the **context** means every page subsequently opened from that context inherits stealth
patches automatically — including any popup or new tab that Google Maps might open. Call
`stealth_sync(context)` immediately after `browser.new_context(...)`, before any
`context.new_page()` call.

### 3. User-Agent string

Use a current, realistic Chrome on Linux desktop UA:

```
Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36
```

This matches the headless Chromium version Playwright ships and avoids the obvious
`HeadlessChrome/` suffix that Google detects.

### 4. Sandbox flags

Container/CI environments often run without kernel namespace support. Pass:

```
--no-sandbox
--disable-setuid-sandbox
--disable-dev-shm-usage
```

`--disable-dev-shm-usage` prevents crashes when `/dev/shm` is small (common in Docker).
These are passed to `p.chromium.launch(args=[...])`.

### 5. Cookie consent dialog strategy

Google's consent dialog appears on first visit and varies by region. Strategy:

- Use a **CSS attribute + text** locator: `button:has-text("Accept all")`. Google also
  serves localised variants; add fallbacks for "Alle akzeptieren" (DE), "Tout accepter"
  (FR), and "Aceitar tudo" (PT) via a combined Playwright `or` locator.
- Wrap the click in a `try/except PlaywrightTimeoutError` with a short timeout (5 000 ms).
  If the dialog never appears (already accepted, different region, or dialog structure
  changed), the block exits silently — do not raise.
- After a successful click, call `page.wait_for_load_state("networkidle")` again because
  dismissing the dialog triggers a Maps reload.

### 6. `wait_until` strategy

`page.goto(..., wait_until="networkidle")` is the primary gate. Google Maps fires many
XHRs; `"networkidle"` (500 ms of no network activity) is the correct signal that the
initial tile load has settled. A secondary `page.wait_for_load_state("networkidle")` call
after consent click covers the post-dismiss reload.

### 7. `scrape()` signature preservation

Keep `def scrape(url: str) -> list[dict]` unchanged. The `url` parameter is unused in
this card (navigation target is hardcoded to Maps home); result parsing is a future card.
Return `[]` (empty list) as a placeholder after the init block so the function signature
is fulfilled and `app.py` does not break.

### 8. Context/browser lifecycle

Use nested `with sync_playwright() as p` + `with p.chromium.launch(...) as browser` +
`with browser.new_context(...) as context` to guarantee teardown on exception. Pages do
not need an explicit `with` block — they are closed when context closes.

### 9. `python-performance-optimization` skill applicability

The skill applies at the network/I/O optimisation layer (Step 3 of the skill: batch I/O,
avoid redundant waits). Relevant here:

- Do not call `page.wait_for_load_state` more than once per navigation cycle; each call is
  a blocking wait.
- Route interception (`page.route("**/*.{png,jpg,svg,gif,woff2}", lambda r: r.abort())`)
  to abort image/font requests is a performance win for scraping — include this in the
  context setup block, before navigation.

## Implementation Steps

### Step 1 — Preserve and extend imports

`scraper.py` already imports `sync_playwright`, `stealth_sync`, `BeautifulSoup`. Add:

```python
from playwright.sync_api import sync_playwright, TimeoutError as PlaywrightTimeoutError
```

`PlaywrightTimeoutError` is needed for the consent-dialog `except` clause.

### Step 2 — Define constants at module level

```python
_MAPS_URL = "https://www.google.com/maps"
_USER_AGENT = (
    "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 "
    "(KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36"
)
_LAUNCH_ARGS = [
    "--no-sandbox",
    "--disable-setuid-sandbox",
    "--disable-dev-shm-usage",
]
_CONSENT_TEXTS = ["Accept all", "Alle akzeptieren", "Tout accepter", "Aceitar tudo"]
_CONSENT_TIMEOUT_MS = 5_000
```

Module-level constants keep the function body readable and make UA/args easy to update.

### Step 3 — Implement `_build_context(browser)`  (private helper)

```python
def _build_context(browser):
    context = browser.new_context(
        user_agent=_USER_AGENT,
        viewport={"width": 1280, "height": 800},
    )
    stealth_sync(context)
    return context
```

Isolating context creation into a helper makes unit testing straightforward (pass a mock
browser) and keeps `scrape()` readable.

### Step 4 — Implement `_dismiss_consent(page)` (private helper)

```python
def _dismiss_consent(page) -> None:
    selector = ", ".join(
        f'button:has-text("{text}")' for text in _CONSENT_TEXTS
    )
    try:
        page.locator(selector).first.click(timeout=_CONSENT_TIMEOUT_MS)
        page.wait_for_load_state("networkidle")
    except PlaywrightTimeoutError:
        pass
```

Using `.first` on the locator avoids a `strict mode violation` if multiple matching
buttons appear. The `except` swallows only `PlaywrightTimeoutError`; unexpected exceptions
(network errors, browser crash) propagate normally.

### Step 5 — Implement `_block_media(page)` (private helper, performance)

Per the `python-performance-optimization` skill (batch I/O, avoid unnecessary downloads):

```python
def _block_media(page) -> None:
    page.route(
        "**/*.{png,jpg,jpeg,svg,gif,webp,woff,woff2,ttf,eot,ico}",
        lambda route: route.abort(),
    )
```

Call this after `context.new_page()` and before `page.goto()`.

### Step 6 — Replace `scrape()` stub body

```python
def scrape(url: str) -> list[dict]:
    with sync_playwright() as p:
        with p.chromium.launch(headless=True, args=_LAUNCH_ARGS) as browser:
            with _build_context(browser) as context:
                page = context.new_page()
                _block_media(page)
                page.goto(_MAPS_URL, wait_until="networkidle")
                _dismiss_consent(page)
    return []
```

`_build_context` returns a context used as a ctx manager — `BrowserContext` supports
`__enter__`/`__exit__` in Playwright ≥ 1.20. Verify version; if not supported, use
`try/finally: context.close()` instead.

### Step 7 — Keep `if __name__ == "__main__"` smoke block

```python
if __name__ == "__main__":
    result = scrape("unused")
    print("Browser init OK, consent dismissed, result:", result)
```

Running `python scraper.py` should print without error. This is the manual smoke test.

## State Management Strategy

- All state is local to the `with sync_playwright()` block. No module-level browser or
  page objects are cached.
- `scrape()` is stateless and re-entrant: each call opens and closes its own browser.
- Future cards will pass extracted data upward via the return value (`list[dict]`); no
  shared mutable state is introduced here.

## Risks and Edge Cases

| Risk | Mitigation |
|------|-----------|
| `playwright-stealth` version does not support `BrowserContext` as arg | Verify `stealth_sync` signature; fall back to calling `stealth_sync(page)` after `context.new_page()` if needed. Document in code. |
| Google changes consent dialog DOM — button text or aria-label shifts | Locator uses `:has-text(...)` which matches partial text; robust to minor label changes. Fallback to `aria-label` selectors (`[aria-label*="Accept"]`) if text changes completely. |
| `networkidle` never fires on slow connections | `page.goto` default timeout is 30 s; Playwright raises `TimeoutError`. Propagate to caller — scraper is non-functional without Maps loading. Add `timeout=60_000` to `goto` for slow envs. |
| Consent dialog inside an iframe | Google uses a same-origin iframe for consent on some regions. If button not found via page-level locator, try `page.frame_locator("iframe").locator(selector).first.click(...)`. Add as fallback inside `_dismiss_consent`. |
| `--no-sandbox` in prod | Acceptable for containerised deployments; document that running as root without sandbox is a known trade-off. |
| `BrowserContext.__enter__` not supported in older Playwright | Use `try/finally: context.close()` pattern as fallback. Pin `playwright>=1.44` in `requirements.txt` to guarantee ctx-manager support. |
| `_block_media` aborts favicons/CSP-required resources | Aborting `ico` and `woff*` is safe for scraping; Maps renders tile layers, not font icons. Monitor for JS errors in future debugging sessions if tiles fail to load. |
| Multiple consent buttons matched by combined selector | `.first` selects the topmost DOM match. On Maps, the "Accept all" button is always the primary CTA and appears first. No risk. |
