## Architecture Decisions

### 1. Container selection: primary + fallback

Google Maps renders the sidebar results as `div[role="feed"]`. This ARIA role selector is stable across Maps versions. A second fallback, `[aria-label*="Results"]`, handles edge cases where the role attribute is absent (A/B testing variants). Selectors are stored in a tuple constant `_FEED_SELECTORS` so they can be extended without touching helper logic.

`_locate_feed(page)` iterates the tuple, returns `.first` on the first matching locator, and raises `RuntimeError` if nothing matches — failing loud is correct here because scrolling a non-existent container would silently return no results.

### 2. Element handle for JS evaluation

Playwright's `locator.element_handle()` returns a stable `JSHandle` that can be passed as an argument to `page.evaluate(...)`. This avoids re-querying the DOM on each scroll iteration (the container element is created once and persists). Use `page.evaluate("(el) => el.scrollHeight", handle)` and `page.evaluate(f"(el) => el.scrollBy(0, {_SCROLL_STEP_PX})", handle)`.

### 3. Scroll-and-then-measure loop order

Scroll **first**, then wait, then measure. Rationale: on the very first iteration, `prev_height = 0` which would immediately trigger the stale counter if we measure before scrolling. Post-scroll measurement correctly reflects whether new content loaded in response to the scroll event.

### 4. Stale counter reset policy

Reset `stale_count` to `0` only when `current_height > prev_height`. Use `<=` (not `==`) because scroll heights can only grow or stay equal; the `<` branch guards against pathological DOM shrinkage. This means three consecutive scrolls that add zero height break the loop.

### 5. End-of-list detection

Google Maps injects a `<div>` or `<span>` containing the text "You've reached the end of the list" after the final result card. Use `page.locator('text="You\'ve reached the end of the list"').count() > 0` as the check. The `count()` call never throws; it returns 0 when absent. Checked at the **top** of each loop iteration so a single extra scroll after the marker is never performed.

### 6. Jitter delay

`time.sleep(random.uniform(_SCROLL_JITTER_MIN, _SCROLL_JITTER_MAX))` between scroll and measure. `random` and `time` are stdlib — no new dependencies. Jitter is applied on every iteration, including iterations where height eventually stays the same, to avoid rate-limit patterns.

### 7. `scrape()` navigation target

Replace `page.goto(_MAPS_URL, ...)` with `page.goto(url, ...)` using the caller-supplied parameter. The `url` parameter was previously unused (documented as placeholder). This card activates it. Consent dismissal and media blocking remain in place; they apply to any Maps URL.

### 8. `playwright-best-practices` skill applicability

The skill's **locators** guidance applies: prefer role/ARIA selectors (`div[role="feed"]`) over CSS class chains — Maps class names are auto-generated and unstable. The **assertions-waiting** guidance applies: do not use fixed `time.sleep` for page navigation waits (those already use `wait_until="networkidle"`); `time.sleep` is intentional and acceptable only for the jitter between scroll steps where we explicitly want a human-paced delay, not a DOM condition.

### 9. `python-performance-optimization` skill applicability

Media blocking (already in `_block_media`) prevents image downloads during scroll. Additionally: obtain the element handle **once** before the loop (not on each iteration) to avoid repeated DOM queries; use a single `page.evaluate` call that both scrolls and returns the new `scrollHeight` to halve the JS round-trips per iteration.

**Updated combined JS call (single round-trip):**
```javascript
(args) => { args[0].scrollBy(0, args[1]); return args[0].scrollHeight; }
```
This replaces two separate `evaluate` calls (scroll + measure) with one, reducing Playwright IPC overhead.

```python
def _locate_feed(page):
    """Return .first locator for the Maps results feed container.

    Raises RuntimeError if no selector in _FEED_SELECTORS matches.
    """
    for selector in _FEED_SELECTORS:
        loc = page.locator(selector)
        if loc.count() > 0:
            return loc.first
    raise RuntimeError(
        f"Maps feed container not found. Tried: {list(_FEED_SELECTORS)}"
    )
```

```python
def _scroll_feed(page) -> None:
    """Scroll the Maps results feed until all results load.

    Stops when 'end of list' notice appears or _SCROLL_STALE_LIMIT consecutive
    scrolls produce no scrollHeight increase.
    """
    feed = _locate_feed(page)
    handle = feed.element_handle()
    prev_height = 0
    stale_count = 0

    while True:
        if _end_of_list_visible(page):
            break

        current_height = page.evaluate(
            "(args) => { args[0].scrollBy(0, args[1]); return args[0].scrollHeight; }",
            [handle, _SCROLL_STEP_PX],
        )
        time.sleep(random.uniform(_SCROLL_JITTER_MIN, _SCROLL_JITTER_MAX))

        if current_height <= prev_height:
            stale_count += 1
            if stale_count >= _SCROLL_STALE_LIMIT:
                break
        else:
            stale_count = 0
            prev_height = current_height
```

## State Management Strategy

- All state is local to `_scroll_feed`'s stack frame: `prev_height`, `stale_count`. No module-level mutable state.
- `scrape()` remains stateless and re-entrant: each call creates and tears down its own browser, context, and page.
- The `handle` (element handle) is obtained once and reused; it is invalidated when the browser context closes, which happens automatically at the end of the `with` block.
- Future result-extraction cards will receive data via `_scroll_feed`'s return value or a passed-in accumulator list — no shared state needed.

## Risks and Edge Cases

| Risk | Mitigation |
|---|---|
| `div[role="feed"]` absent before search results load | `_locate_feed` is called after `page.goto(url, wait_until="networkidle")`; results panel should be present. If Maps uses lazy-render for the feed, add `page.locator('div[role="feed"]').wait_for(state="visible", timeout=15_000)` inside `_locate_feed` before `.count()`. |
| `element_handle()` returns `None` | Playwright returns `None` for non-existent elements. Add `assert handle is not None` or a `if handle is None: raise RuntimeError(...)` guard inside `_scroll_feed` before the loop. |
| JS `scrollBy` no-ops on non-scrollable container | If Maps wraps the feed inside a parent scroller, `scrollHeight` won't change. The stale-count mechanism handles this by breaking after 3 attempts; logging a warning is advisable. |
| `text="..."` locator syntax across Playwright versions | Playwright ≥ 1.27 uses `page.get_by_text(...)` as preferred API. `page.locator('text="..."')` is the legacy but still supported form. Both work with `>=1.44`. If Google's text changes locale (e.g. "Sie haben das Ende der Liste erreicht"), extend `_END_OF_LIST_TEXT` to a tuple and iterate — scope expansion for a future card. |
| Combined `scrollBy + scrollHeight` JS array argument | `page.evaluate("(args) => {...}", [handle, step])` passes a JavaScript array. The handle becomes `args[0]` and the integer becomes `args[1]`. Verify Playwright's serialization of mixed `[JSHandle, int]` arrays — if it fails, split back into two separate `evaluate` calls. |
| Infinite loop on Maps pages without a results panel | `_scroll_feed` is only called from `scrape(url)` where `url` is expected to be a Maps search URL. If called on a non-search page, `_locate_feed` raises `RuntimeError`, which propagates to the caller — correct behavior. |
| `time.sleep` in tests causing slow test runs | All tests patch `scraper.time` (the `time` module as imported in scraper) or `scraper.random.uniform`. Confirm patches target `scraper.time.sleep`, not `time.sleep` directly, since Python mock patches the reference in the module under test. |
| Previous `test_scrape_navigates_to_maps_url` test breaks | That test asserts `page.goto` called with `_MAPS_URL`. After this card, `scrape()` uses `url` param. Update that test in Step 5.6 as documented. |
