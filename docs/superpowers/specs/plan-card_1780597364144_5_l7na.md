**Goal:** Optimize `scraper.py` to avoid bot detection without premium proxies by adding inter-profile randomized delays and a `scrape_multi()` grid-query strategy that bypasses Google Maps' ~120-result cap.

**Architecture:** Keep `scrape(url)` backward-compatible by extracting its browser loop body into `_scrape_one_url(browser, url)`. Add a per-profile `time.sleep(random.uniform(2, 5))` inside `_collect_nodes` after each successfully evaluated anchor.

## Architecture Decisions

1. **One shared browser, N fresh contexts** — `scrape_multi` launches Chromium once. Each query creates and destroys its own `BrowserContext` via `_scrape_one_url`. This clears cookies, localStorage, and session state between queries (the "context reset") while avoiding the overhead of re-launching Chromium.

2. **Delay placement in `_collect_nodes`** — The sleep fires after `results.append(html)` inside the anchor loop, only for successfully evaluated unique profiles. Duplicate anchors (`continue` on seen key) and errored anchors (`continue` in except) do not trigger a sleep. This faithfully mimics a human reading each card before moving on.

3. **Deduplication key** — `f"{name}|{phone}"`. Name alone isn't safe (chains have same name in different areas). Phone alone misses businesses without phone. Together they identify a unique real-world location across overlapping sub-region queries.

4. **`scrape(url)` stays unchanged** — Its public signature `scrape(url: str) -> list[dict]` is preserved. Internally it now delegates to `_scrape_one_url`. All existing tests remain green.

5. **`_query_to_url` uses `urllib.parse.quote_plus`** — Converts `"Cafes in Upper East Side NY"` → `"https://www.google.com/maps/search/Cafes+in+Upper+East+Side+NY"`. `quote_plus` is stdlib, no new dependency.

```python
def _collect_nodes(page) -> list[str]:
    feed_el = (
        page.query_selector('div[role="feed"]')
        or page.query_selector('[aria-label*="Results"]')
    )
    if not feed_el:
        return []
    anchors = feed_el.query_selector_all(_PLACE_LINK_SELECTOR)
    seen: set[str] = set()
    results: list[str] = []
    for anchor in anchors:
        try:
            href = anchor.get_attribute('href') or ''
            key = href.split('?')[0]
            if key in seen:
                continue
            seen.add(key)
            html = anchor.evaluate(
                '(el) => (el.closest("[jsaction]") || el.parentElement).innerHTML'
            )
            results.append(html)
            time.sleep(random.uniform(_PROFILE_DELAY_MIN, _PROFILE_DELAY_MAX))
        except Exception:
            continue
    return results
```

```python
def _scrape_one_url(browser, url: str) -> list[dict]:
    """Run one full scrape cycle against `url` on an existing browser.

    Creates a fresh BrowserContext (clears cookies/storage), navigates,
    scrolls, collects nodes, and parses results.  The context is closed
    when the with-block exits regardless of errors.
    """
    with _build_context(browser) as ctx:
        page = ctx.new_page()
        _block_media(page)
        page.goto(url, wait_until="networkidle")
        _dismiss_consent(page)
        _scroll_feed(page)
        nodes_html = _collect_nodes(page)
    return [r for r in (_parse_business_node(h) for h in nodes_html) if r.get('name')]


def scrape(url: str) -> list[dict]:
    """Scrape `url` and return list of result dicts."""
    with sync_playwright() as p:
        with p.chromium.launch(headless=True, args=_LAUNCH_ARGS) as browser:
            return _scrape_one_url(browser, url)
```

```python
def scrape_multi(queries: list[str]) -> list[dict]:
    """Scrape multiple sub-region queries and return deduplicated results.

    Each query runs in its own fresh BrowserContext so cookies and
    local-storage tracking state are cleared between iterations.
    A randomised inter-query delay mimics human pacing between searches.
    Results from all queries are merged and deduplicated by name+phone key.
    """
    seen_keys: set[str] = set()
    results: list[dict] = []
    with sync_playwright() as p:
        with p.chromium.launch(headless=True, args=_LAUNCH_ARGS) as browser:
            for i, query in enumerate(queries):
                url = _query_to_url(query)
                batch = _scrape_one_url(browser, url)
                for record in batch:
                    key = f"{record.get('name', '')}|{record.get('phone', '')}"
                    if key not in seen_keys:
                        seen_keys.add(key)
                        results.append(record)
                if i < len(queries) - 1:
                    time.sleep(
                        random.uniform(_INTER_QUERY_DELAY_MIN, _INTER_QUERY_DELAY_MAX)
                    )
    return results
```

## State Management Strategy

- **No module-level mutable state** — `scrape_multi` holds `seen_keys` and `results` as local variables; they are garbage-collected after the function returns. No global caches.
- **Context reset between queries** — `_scrape_one_url` creates a new `BrowserContext` via `_build_context` and closes it via the `with` block on exit. Each query starts with empty cookies, localStorage, and session storage.
- **Browser-level state shared across queries** — the browser process persists for performance (reuse JIT-compiled V8). Only context-level state is cleared. This is sufficient; Google Maps fingerprinting is context-scoped.
- **Deduplication state** (`seen_keys`) lives for the duration of one `scrape_multi` call, then is discarded. Repeated calls to `scrape_multi` with overlapping queries will re-scrape but still return deduplicated results within that call.

## Risks and Edge Cases

| Risk | Mitigation |
|---|---|
| `_collect_nodes` sleep adds 2–5s × ~120 results = up to 10 minutes per query | Acceptable trade-off for stealth; document in `scrape_multi` docstring |
| Two businesses with same name and no phone produce same dedup key (`"Cafe A\|"`) | Names with no phone are still deduplicated across sub-region queries — acceptable because they likely are the same business |
| `_query_to_url` receives a full URL instead of a query string | `quote_plus` will encode `://` as `%3A%2F%2F` producing a broken URL; callers of `scrape_multi` are responsible for passing query strings, not URLs — documented in docstring |
| `scrape_multi([])` with empty list — browser is still launched | Acceptable; the `with p.chromium.launch(...)` block enters then immediately exits. Cost is negligible. |
| `_build_context` returns a context that is NOT a context manager | Playwright's `BrowserContext` is always a CM. If a future mock does not implement `__enter__/__exit__`, `_scrape_one_url` will raise `AttributeError`. Tests cover this by using `MagicMock` with explicit `__enter__/__exit__`. |
| Inter-query delay does not fire after the last query | Confirmed by `test_inter_query_sleep_not_called_for_single_query` and `test_inter_query_sleep_called_n_minus_1_times`. |
| `_SCROLL_JITTER_*` constants still used in `_scroll_feed` independently | Scroll-phase and profile-phase delays are independent. Both apply in a real run. No conflict. |
