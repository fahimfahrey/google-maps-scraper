# Plan: Fix Playwright Browser Install on Unsupported Platforms (Ubuntu 26.04)

## Overview

`setup.sh` fails on Ubuntu 26.04 because Playwright 1.60.0 has no managed browser binaries compiled for `ubuntu26.04-x64`. Both `playwright install chromium` and `playwright install firefox` exit non-zero. The current fallback chain (chromium → firefox) is exhausted, leaving the user unable to run the scraper.

Fix: extend the fallback chain in `setup.sh` to detect and use **system-installed browsers** when Playwright-managed install fails. Extend `scraper.py` to accept an `executable_path` pointing to the system binary. No new dependencies, no Python version bumps.

Skill to apply throughout: `.agents/skills/playwright-best-practices/SKILL.md` (infrastructure/configuration section).

## Architecture Decisions

1. **System-browser probe over skip-validation flag.** `PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1` might download a binary that segfaults on the wrong glibc. Driving a system-installed browser is safer and already tested by the OS packager.

2. **Two separate marker files, not one.** `.playwright_browser` (already exists) stores the engine name; add `.playwright_browser_path` to store the executable path. Separating them avoids a breaking format change and keeps backward compat for existing setups where Playwright manages the browser (path file absent → Playwright-managed).

3. **Precedence chain for executable path.** `PLAYWRIGHT_BROWSER_EXECUTABLE` env var > `.playwright_browser_path` file > absent (use Playwright-managed binary). Mirrors the existing pattern for engine selection.

4. **Firefox user-agent patch.** When using Firefox via `executable_path`, the Chromium-impersonating `_USER_AGENT` is wrong. scraper.py must omit the custom user-agent for the Firefox path (use browser default).

5. **`playwright_stealth` on Firefox.** `Stealth()` is designed for Chromium. When Firefox is the engine, skip stealth injection to avoid exceptions (current code already has no stealth guard; add one).

## Implementation Steps

### Step 1 — Extend `setup.sh` system-browser probe

After the `playwright install firefox` failure branch, before the final `exit 1`, insert:

```bash
# --- Fallback 3: use system-installed browser ---
SYSTEM_CHROMIUM=""
for candidate in google-chrome-stable google-chrome chromium-browser chromium; do
    if command -v "$candidate" &>/dev/null; then
        SYSTEM_CHROMIUM=$(command -v "$candidate")
        break
    fi
done

SYSTEM_FIREFOX=""
if [[ -z "$SYSTEM_CHROMIUM" ]]; then
    if command -v firefox &>/dev/null; then
        SYSTEM_FIREFOX=$(command -v firefox)
    fi
fi

if [[ -n "$SYSTEM_CHROMIUM" ]]; then
    echo "Using system Chromium: $SYSTEM_CHROMIUM" >&2
    BROWSER_ENGINE="chromium"
    echo "$SYSTEM_CHROMIUM" > .playwright_browser_path
elif [[ -n "$SYSTEM_FIREFOX" ]]; then
    echo "Using system Firefox: $SYSTEM_FIREFOX" >&2
    BROWSER_ENGINE="firefox"
    echo "$SYSTEM_FIREFOX" > .playwright_browser_path
else
    echo "ERROR: Neither Chromium nor Firefox could be installed." >&2
    exit 1
fi
```

Also: move the `echo "$BROWSER_ENGINE" > .playwright_browser` line so it runs in **all** success branches (Playwright-managed and system-browser).

Remove the top-level `set -euo pipefail` guard from the `playwright install` calls by wrapping them in `if ! ... 2>&1; then` blocks (already done for chromium; apply same pattern for firefox). The inner blocks must not trigger the outer `set -e`.

### Step 2 — Add `_read_browser_executable()` to `scraper.py`

Add constant at module level (after `_BROWSER_MARKER_FILE`):

```python
_BROWSER_PATH_FILE = ".playwright_browser_path"
```

Add function after `_read_browser_engine()`:

```python
def _read_browser_executable() -> str | None:
    """Return absolute path to browser binary, or None to use Playwright-managed binary.

    Precedence: PLAYWRIGHT_BROWSER_EXECUTABLE env var > .playwright_browser_path file.
    """
    import os
    path = os.environ.get("PLAYWRIGHT_BROWSER_EXECUTABLE", "").strip()
    if path:
        return path
    try:
        with open(_BROWSER_PATH_FILE) as fh:
            path = fh.read().strip()
        if path:
            return path
    except OSError:
        pass
    return None
```

### Step 3 — Update `_launch_browser()` in `scraper.py`

Replace the existing `_launch_browser` body:

```python
def _launch_browser(p):
    """Launch the appropriate headless browser based on engine selection."""
    engine = _read_browser_engine()
    exe = _read_browser_executable()
    launch_kwargs = {"headless": True}
    if exe:
        launch_kwargs["executable_path"] = exe
    if engine == "firefox":
        launch_kwargs["args"] = _FIREFOX_LAUNCH_ARGS
        return p.firefox.launch(**launch_kwargs)
    launch_kwargs["args"] = _LAUNCH_ARGS
    return p.chromium.launch(**launch_kwargs)
```

### Step 4 — Guard stealth injection in `_build_context()` / wherever Stealth is applied

Locate the `Stealth()` usage in `scraper.py` (grep for `Stealth`). Wrap with engine check:

```python
if _read_browser_engine() != "firefox":
    await stealth.apply(page)   # or however it's currently called
```

### Step 5 — Guard user-agent in `_build_context()`

Locate where `_USER_AGENT` is set on `new_context(...)`. Conditionally pass it:

```python
ctx_kwargs = { ... }
if _read_browser_engine() != "firefox":
    ctx_kwargs["user_agent"] = _USER_AGENT
context = browser.new_context(**ctx_kwargs)
```

## State Management Strategy

- `.playwright_browser` — single line: `chromium` or `firefox`. Written by `setup.sh`. Read by `scraper.py:_read_browser_engine()`. Unchanged format.
- `.playwright_browser_path` — single line: absolute path to system browser binary, or absent when Playwright manages the binary. Written by `setup.sh` only in the system-browser fallback branch. Read by `scraper.py:_read_browser_executable()`.
- Both files are git-ignored (check `.gitignore`; add entries if missing).
- `PLAYWRIGHT_BROWSER` and `PLAYWRIGHT_BROWSER_EXECUTABLE` env vars override file-based config for CI / Docker environments.

## Risks and Edge Cases

| Risk | Mitigation |
|------|------------|
| System Chromium is too old for Google Maps (needs modern JS engine) | Log the detected path + version during setup; user can override via `PLAYWRIGHT_BROWSER_EXECUTABLE` |
| Stealth guard causes regression where it was previously applied to Firefox (no-op but harmless) | Existing test suite covers scrape flow; stealth skip only applies when engine=firefox |
| `.playwright_browser_path` file persists across reinstalls and points to moved binary | `setup.sh` overwrites the file on every run; stale paths only an issue if user deletes the binary without re-running setup.sh — acceptable, error message is clear |
| `set -euo pipefail` in setup.sh — intermediate failures in probe loop abort script | Each `command -v` call is safe (exits 0 or 1); the `for` loop body won't trigger `set -e` on `command -v` failure |
| Firefox + playwright_stealth interaction varies by version | Stealth skip is guarded; if user later switches to chromium, stealth re-applies automatically |
| `executable_path` ignored when Playwright CDN binary exists for that engine | Only `.playwright_browser_path` absence → no path passed → Playwright manages. Presence → path always passed. No conflict. |
| Ubuntu 26.04 may ship Chromium as a snap (path is `/snap/bin/chromium`) | Snap binary works as `executable_path`; `command -v chromium` resolves it correctly on Ubuntu snap installs |
