**Goal:** Add a data-extraction pipeline to `scraper.py` that, after `_scroll_feed()` exhausts the Maps results panel, collects the inner HTML of every discovered business node, parses each with BeautifulSoup4 + lxml, and returns a populated `list[dict]` from `scrape()`. ## Architecture Decisions

### 1. Stable business-node discovery: `/maps/place/` link anchors

Google Maps renders each business result as a block containing an `<a>` element whose `href` contains `/maps/place/`. This structural property — a URL path segment — is controlled by Google's routing layer and does not change with A/B visual redesigns. Using `page.query_selector_all('a[href*="/maps/place/"]')` from within the feed context gives one handle per business listing.

To obtain the *container* (not just the anchor), walk up the DOM to the closest ancestor that has a `jsaction` attribute — these elements are Google's event-delegation roots and wrap a complete business card. Fall back to `parentElement` if `jsaction` is absent. This yields a stable bounding node for each result.

```python
# Playwright-side JS to get the container from an anchor handle
"(el) => (el.closest('[jsaction]') || el.parentElement).innerHTML"
```

### 2. Feed-scoped query to avoid duplicate captures

Query *within* the feed locator, not the whole page, to prevent picking up promoted pins or sidebar-injected ads that also contain `/maps/place/` links but are not feed result items.

```python
feed_el = page.query_selector('div[role="feed"]') or page.query_selector('[aria-label*="Results"]')
nodes = feed_el.query_selector_all('a[href*="/maps/place/"]') if feed_el else []
```

### 3. De-duplication by place URL

Multiple anchors inside one card (title link + photo link) share the same `/maps/place/` path. De-duplicate by extracting the path segment from each `href` before collecting HTML: keep only the first anchor per unique place path.

```python
seen: set[str] = set()
for anchor in anchors:
    href = anchor.get_attribute('href') or ''
    # Extract stable /maps/place/Name/ChIxxx... path, ignoring query string
    key = href.split('?')[0]
    if key not in seen:
        seen.add(key)
        # collect this node
```

### 4. lxml parser for BeautifulSoup (per beautifulsoup-parsing skill)

`BeautifulSoup(html, 'lxml')` is the recommended parser: fastest, lenient with malformed HTML (Google renders complex nested markup), and already declared in `requirements.txt`. Never use `html.parser` for production scrapers — it is stricter and slower on large fragments.

### 5. Stable CSS selectors — no Tailwind-style class names

Google Maps auto-generates class names (e.g. `fontBodyMedium`, `UsdlK`, `hfpxzc`) that change with each deployment. The plan explicitly forbids using them. Stable selectors used:

| Field | Primary stable selector | Why stable |
|---|---|---|
| Name | `a[href*="/maps/place/"]` → `aria-label` attribute | Google populates `aria-label` on the business link for accessibility |
| Name fallback | `[role="heading"]` first match | ARIA `role` attribute is semantically controlled |
| Rating | `[aria-label*=" stars"]` → parse numeric prefix | Screen-reader label on star icon; Google accessibility requirement |
| Rating fallback | `span[aria-label*="out of 5"]` | Alternative Maps rendering |
| Review count | regex `\(\d[\d,]*\)` on text content | Parenthesised integer is the Maps convention regardless of styling |
| Phone | `[data-item-id*="phone"]` → text content | `data-item-id` is a Maps data attribute tied to the listing data model |
| Phone fallback | regex on `.get_text()` | International + local phone patterns |
| Website | `a[data-item-id="authority"]` → `href` | `data-item-id="authority"` is Google's canonical website marker |
| Website fallback | `a[href^="http"]` not containing `google.com` | Structural: external `http` link not part of Google infrastructure |

### 6. Phone regex — international + local coverage

```python
_PHONE_REGEX = re.compile(
    r'(?:'
    r'\+\d{1,3}[\s\-\.]?\(?\d{1,4}\)?[\s\-\.]?\d{1,4}[\s\-\.]?\d{1,9}'  # +CC (area) local
    r'|\(?\d{3}\)?[\s\-\.]?\d{3}[\s\-\.]?\d{4}'                           # NANP: (555) 555-5555
    r'|\d{4,5}[\s\-]\d{5,6}'                                               # UK: 01234 567890
    r')'
)
```

The regex is compiled once at module level (`_PHONE_REGEX`) — no per-call recompilation overhead. Applied to `soup.get_text(' ')` (space-joined) after the `data-item-id` primary path fails.

### 7. Per-field `try/except Exception` wrapping

Every extractor returns a sensible empty default (`''` for strings) and catches all `Exception` subclasses. This means:
- A `None` element, a missing attribute, a regex with no match, or an unexpected DOM structure in one field does NOT propagate and does NOT suppress the other fields.
- `_parse_business_node` itself is also wrapped so a completely unparseable node yields an empty dict that is filtered out in `scrape()`.

### 8. Result filtering — skip nodes with no name

After `_parse_business_node`, discard any dict with `name == ''`. These are either photo anchors, ad fragments, or container nodes that did not resolve to a real business.

### 9. `scrape()` return value — populated list

Replace the current `return []` stub with:

```python
nodes_html = _collect_nodes(page)
results = [r for r in (_parse_business_node(h) for h in nodes_html) if r.get('name')]
return results
```

### 10. No new dependencies

`beautifulsoup4`, `lxml`, and `re` (stdlib) are already present. `re` needs an explicit `import re` added to `scraper.py`.

```python
def _extract_rating(soup) -> str:
    try:
        star_el = soup.select_one('[aria-label*=" stars"]') or \
                  soup.select_one('[aria-label*=" star"]')
        if star_el:
            m = re.search(r'(\d+\.?\d*)\s+stars?', star_el.get('aria-label', ''))
            if m:
                return m.group(1)
        out_of_el = soup.select_one('[aria-label*="out of 5"]')
        if out_of_el:
            m = re.search(r'(\d+\.?\d*)\s+out of 5', out_of_el.get('aria-label', ''))
            if m:
                return m.group(1)
    except Exception:
        pass
    return ''
```

```python
def _collect_nodes(page) -> list[str]:
    """Collect inner HTML strings for each unique business node in the feed.

    Queries within the feed container to avoid promoted pins outside the panel.
    De-duplicates by /maps/place/ path (strips query string) so photo anchors
    and title anchors pointing to the same place are only collected once.
    """
    feed_el = (
        page.query_selector('div[role="feed"]')
        or page.query_selector('[aria-label*="Results"]')
    )
    if not feed_el:
        return []

    anchors = feed_el.query_selector_all(_PLACE_LINK_SELECTOR)
    seen: set[str] = set()
    results: list[str] = []

    for anchor in anchors:
        try:
            href = anchor.get_attribute('href') or ''
            key = href.split('?')[0]
            if key in seen:
                continue
            seen.add(key)
            html = anchor.evaluate(
                '(el) => (el.closest("[jsaction]") || el.parentElement).innerHTML'
            )
            results.append(html)
        except Exception:
            continue

    return results
```

```python
    """Scrape `url` and return list of result dicts."""
```

## State Management Strategy

- All parsing state is local to function call stacks — no module-level mutable state introduced.
- `_collect_nodes` returns a `list[str]` (pure data, no Playwright handles) so parsing is decoupled from browser lifecycle. The browser closes before `_parse_business_node` runs, preventing any accidental live-DOM dependency in the BS4 layer.
- `_PHONE_REGEX` is compiled once at import time and shared across calls (read-only).
- `scrape()` remains stateless and re-entrant: each invocation owns its full browser/context/page lifecycle via `with` blocks.
- No shared mutable accumulator — the list comprehension in `scrape()` is a pure transformation.

## Risks and Edge Cases

| Risk | Mitigation |
|---|---|
| `aria-label` on `<a>` absent in some Maps variants | `_extract_name` falls back to `[role="heading"]`; returns `''` if both miss; node filtered from final results |
| `aria-label` contains "stars" as part of a longer phrase ("4.5 stars 321 reviews") | `re.search(r'(\d+\.?\d*)\s+stars?', ...)` extracts the leading numeric group; additional trailing text is ignored |
| Review count `(1.5K)` — abbreviated format | Current regex `\(\d[\d,]*\)` does not match `K`-abbreviated counts. Google Maps uses plain integers for <10,000 results; abbreviated form appears at very high counts. Flag as a known limitation — extend regex in a future card if needed |
| `element.closest('[jsaction]')` returns an ancestor too high in the DOM | The `innerHTML` captured would be larger than one business card, causing over-extraction. Mitigated: `jsaction` elements in the Maps feed are typically the direct card container. If a test shows overlapping results, tighten the selector to `.closest('[data-result-index]')` as a plan-amendment |
| `page.query_selector_all` inside feed returns anchors from injected ad cards | Ad cards share the `/maps/place/` URL pattern. De-duplication by place path prevents the same business from appearing twice, but a distinct ad business would still appear once. No mitigation in scope — ad filtering is a future card |
| `get_attribute('href')` returns `None` for anchors with no `href` | `href.split('?')[0]` would fail. `href = anchor.get_attribute('href') or ''` guards this; empty string key is added to `seen` and subsequent empty-href anchors are also deduplicated |
| `anchor.evaluate(...)` throws Playwright `Error` on detached element | Per-anchor `try/except Exception: continue` in `_collect_nodes` silently skips detached nodes |
| BS4 lxml parser not installed | `requirements.txt` already lists `lxml`; install error surfaced at `pip install` time, not at parse time. No additional guard needed |
| `scrape()` called on a non-Maps URL | `_locate_feed` raises `RuntimeError` (no feed container); `_collect_nodes` query returns `[]` (no `/maps/place/` links); `scrape()` returns `[]`. Both failure modes are safe |
| `nodes_html` captured inside `with` block but list comprehension runs outside | All HTML is fully captured as Python strings before the browser closes. BS4 parses string data only — no Playwright handles escape the `with` scope. This is the intentional architecture (see State Management) |
| Multiple `<a>` tags share same place path but different `jsaction` ancestors | First anchor's `jsaction` ancestor is collected; subsequent duplicates are skipped by the `seen` set. If the first anchor resolves to a photo thumbnail with less data than the title anchor, the extracted node may be sparse. Reorder to prefer the title `<a>` — future refinement if coverage data shows empty extractions |
