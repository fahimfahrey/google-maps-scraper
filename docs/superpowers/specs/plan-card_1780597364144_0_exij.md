# Plan: Python 3.11+ Scraper Dev Environment Setup

## Overview

Bootstrap a local web-scraper project with four source files (`scraper.py`, `database.py`, `app.py`, `requirements.txt`), a shell initialisation script, and a `.gitignore`. No application logic is implemented — only structure, dependency manifests, and environment wiring. Playwright's standalone Chromium binary is fetched via `playwright install chromium` inside the venv.

## Architecture Decisions

1. **Python version gate** — `setup.sh` checks `python3 --version` and aborts if < 3.11. Uses `python3 -m venv` (stdlib, no extra tools).
2. **venv location** — `.venv/` at project root. Conventional name; excluded by `.gitignore`.
3. **Dependency pinning** — `requirements.txt` lists bare package names without version pins (as specified). Versions resolved at install time. If reproducibility is needed later, pin via `pip freeze > requirements.lock`.
4. **playwright-stealth availability** — Package name on PyPI is `playwright-stealth`. Install proceeds with `pip install -r requirements.txt`. The `playwright install chromium` step runs *after* pip install so the CLI is available.
5. **Stub content** — Each `.py` file contains: module-level docstring describing its role, necessary top-level imports, and a `if __name__ == "__main__":` guard. No business logic — avoids import errors when running `streamlit run app.py` against empty stubs.
6. **Database file naming** — `database.py` will eventually write `data.db` (SQLite). `.gitignore` excludes `*.db` and `*.sqlite`.
7. **No Docker / no CI** — out of scope per task.

### Step 5 — Create `setup.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail

# Require Python 3.11+
PYTHON=$(command -v python3 || true)
if [[ -z "$PYTHON" ]]; then
    echo "ERROR: python3 not found" >&2
    exit 1
fi

PY_VERSION=$("$PYTHON" -c "import sys; print(f'{sys.version_info.major}.{sys.version_info.minor}')")
REQUIRED="3.11"
if [[ "$(printf '%s\n' "$REQUIRED" "$PY_VERSION" | sort -V | head -1)" != "$REQUIRED" ]]; then
    echo "ERROR: Python $PY_VERSION < $REQUIRED required" >&2
    exit 1
fi

# Create venv
"$PYTHON" -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install --upgrade pip
pip install -r requirements.txt

# Fetch standalone Chromium binary
playwright install chromium

echo ""
echo "Setup complete. Activate with: source .venv/bin/activate"
echo "Run UI with:                   streamlit run app.py"
```

Make executable: `chmod +x setup.sh` (done inside the script write or noted for the implementer).

## Risks and Edge Cases

| Risk | Mitigation |
|---|---|
| `playwright-stealth` PyPI name mismatch | Verify with `pip index versions playwright-stealth` before finalising `requirements.txt`; fallback: `playwright_stealth` |
| System Python < 3.11 on target machine | `setup.sh` version gate aborts early with clear error |
| `playwright install chromium` requires `~/.cache` write access | Document in README; CI may need `--with-deps` flag |
| `venv` activation path differs on Windows | Script targets Unix (`source .venv/bin/activate`); Windows users need `.venv\Scripts\activate.bat` — document caveat |
| Large Chromium download (~130 MB) on slow networks | Expected; no mitigation needed beyond documentation |
| Importing `database.py` before `data.db` exists | `get_connection()` uses `sqlite3.connect` which creates the file on first call — safe |
| `playwright-stealth` may lag behind Playwright releases | Pin versions if stealth/Playwright API mismatch causes import errors |
