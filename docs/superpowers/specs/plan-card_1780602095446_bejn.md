# Plan: Fix Playwright Chromium Install Failure on Ubuntu 26.04

## Overview

`setup.sh` calls `playwright install chromium`, which fails on Ubuntu 26.04 LTS
("Resolute Raccoon") because Playwright 1.60.0's pre-built Chromium bundle does not
include an ubuntu26-x64 binary. The script runs under `set -euo pipefail`, so the
error aborts setup entirely, leaving the app unable to run.

Root cause: Playwright's browser-download code gates each browser/OS combination
against a hard-coded support matrix. Ubuntu 26.04 postdates the 1.60.0 release and
is not in that matrix for Chromium.

Fix strategy: make `setup.sh` try Chromium first and fall back to Firefox (which
has broader Linux support and works on Ubuntu 26.04). Record the installed engine in
a `.playwright_browser` marker file. Make `scraper.py` read that marker (or the
`PLAYWRIGHT_BROWSER` env var) and launch the correct browser, with engine-specific
launch arguments.

`playwright_stealth` v2.x (already installed) supports both Chromium and Firefox
contexts, so stealth functionality is preserved.

## Architecture Decisions

### A: Marker file over env-var-only
The `PLAYWRIGHT_BROWSER` env var is the override mechanism, but it requires the user
to export it manually every session. A `.playwright_browser` text file written by
`setup.sh` makes the chosen engine persist automatically across sessions without
shell-profile changes. `_read_browser_engine()` checks the env var first (higher
priority), then the marker file, then defaults to `"chromium"`.

### B: Firefox as the fallback (not system Chromium)
Playwright's `firefox` channel ships its own binary and is supported on all Linux
distros with glibc ≥ 2.17. System Chromium (via apt/snap) requires resolving
`executable_path` at runtime and is fragile across distro versions. Firefox is the
simpler, portable option.

### C: Chromium launch args are Chromium-only
`_LAUNCH_ARGS` (`--no-sandbox`, `--disable-setuid-sandbox`, `--disable-dev-shm-usage`)
are Chromium-specific flags. Firefox ignores some but errors on others. Pass them only
when launching Chromium.

### D: `set -euo pipefail` preserved; only the browser install block uses fallback
The rest of `setup.sh` must still fail fast. Use a subshell with `||` to handle the
browser install failure gracefully without disabling global `pipefail`.

## Implementation Steps

### Step 1 — Modify `setup.sh` (browser install section)

Replace the single `playwright install chromium` line with a fallback block:

```bash
# Fetch standalone browser binary (Chromium preferred; Firefox fallback for
# distros not yet in Playwright's Chromium support matrix, e.g. Ubuntu 26.04)
BROWSER_ENGINE="chromium"
if ! .venv/bin/playwright install chromium 2>&1; then
    echo "WARNING: Chromium not supported on this platform. Trying Firefox..." >&2
    if ! .venv/bin/playwright install firefox 2>&1; then
        echo "ERROR: Neither Chromium nor Firefox could be installed." >&2
        exit 1
    fi
    BROWSER_ENGINE="firefox"
fi
echo "$BROWSER_ENGINE" > .playwright_browser
echo "Browser engine: $BROWSER_ENGINE (written to .playwright_browser)"
```

Use `.venv/bin/playwright` (not bare `playwright`) so the venv is always used
regardless of shell activation state.

Update the final output lines to mention `.playwright_browser`:
```bash
echo "Run UI with:                   streamlit run app.py"
echo "Browser engine:                $(cat .playwright_browser 2>/dev/null || echo chromium)"
```

### Step 2 — Modify `scraper.py`

#### 2a: Add constant and `_read_browser_engine()`

After the existing module-level constants (after `_LAUNCH_ARGS`), add:

```python
_BROWSER_MARKER_FILE = ".playwright_browser"
_FIREFOX_LAUNCH_ARGS: list[str] = []   # Firefox rejects chromium-only flags

def _read_browser_engine() -> str:
    """Return the browser engine to use.

    Precedence: PLAYWRIGHT_BROWSER env var > .playwright_browser file > 'chromium'.
    """
    import os
    engine = os.environ.get("PLAYWRIGHT_BROWSER", "").strip().lower()
    if engine in ("chromium", "firefox"):
        return engine
    try:
        with open(_BROWSER_MARKER_FILE) as fh:
            engine = fh.read().strip().lower()
        if engine in ("chromium", "firefox"):
            return engine
    except OSError:
        pass
    return "chromium"
```

#### 2b: Add `_launch_browser(p)`

```python
def _launch_browser(p):
    """Launch the appropriate headless browser based on engine selection."""
    engine = _read_browser_engine()
    if engine == "firefox":
        return p.firefox.launch(headless=True, args=_FIREFOX_LAUNCH_ARGS)
    return p.chromium.launch(headless=True, args=_LAUNCH_ARGS)
```

### Step 3 — Modify `tests/test_scraper.py`

Add a new test class `TestReadBrowserEngine` and `TestLaunchBrowser` (and update
`TestScrape` / `TestScrapeMulti`).

#### 3a: `TestReadBrowserEngine`

```python
class TestReadBrowserEngine:
    """Tests for _read_browser_engine."""

    def test_env_var_chromium(self, monkeypatch):
        monkeypatch.setenv("PLAYWRIGHT_BROWSER", "chromium")
        assert scraper._read_browser_engine() == "chromium"

    def test_env_var_firefox(self, monkeypatch):
        monkeypatch.setenv("PLAYWRIGHT_BROWSER", "firefox")
        assert scraper._read_browser_engine() == "firefox"

    def test_env_var_takes_precedence_over_file(self, monkeypatch, tmp_path):
        monkeypatch.setenv("PLAYWRIGHT_BROWSER", "chromium")
        marker = tmp_path / ".playwright_browser"
        marker.write_text("firefox")
        monkeypatch.setattr(scraper, "_BROWSER_MARKER_FILE", str(marker))
        assert scraper._read_browser_engine() == "chromium"

    def test_reads_marker_file_when_no_env(self, monkeypatch, tmp_path):
        monkeypatch.delenv("PLAYWRIGHT_BROWSER", raising=False)
        marker = tmp_path / ".playwright_browser"
        marker.write_text("firefox")
        monkeypatch.setattr(scraper, "_BROWSER_MARKER_FILE", str(marker))
        assert scraper._read_browser_engine() == "firefox"

    def test_defaults_to_chromium_when_no_env_no_file(self, monkeypatch, tmp_path):
        monkeypatch.delenv("PLAYWRIGHT_BROWSER", raising=False)
        monkeypatch.setattr(scraper, "_BROWSER_MARKER_FILE", str(tmp_path / "missing"))
        assert scraper._read_browser_engine() == "chromium"

    def test_invalid_engine_in_env_falls_back_to_file(self, monkeypatch, tmp_path):
        monkeypatch.setenv("PLAYWRIGHT_BROWSER", "safari")
        marker = tmp_path / ".playwright_browser"
        marker.write_text("firefox")
        monkeypatch.setattr(scraper, "_BROWSER_MARKER_FILE", str(marker))
        assert scraper._read_browser_engine() == "firefox"
```

#### 3b: `TestLaunchBrowser`

```python
class TestLaunchBrowser:
    """Tests for _launch_browser."""

    def test_launches_chromium_by_default(self, monkeypatch):
        monkeypatch.setattr(scraper, "_read_browser_engine", lambda: "chromium")
        mock_p = MagicMock()
        scraper._launch_browser(mock_p)
        mock_p.chromium.launch.assert_called_once_with(
            headless=True, args=scraper._LAUNCH_ARGS
        )
        mock_p.firefox.launch.assert_not_called()

    def test_launches_firefox_when_engine_firefox(self, monkeypatch):
        monkeypatch.setattr(scraper, "_read_browser_engine", lambda: "firefox")
        mock_p = MagicMock()
        scraper._launch_browser(mock_p)
        mock_p.firefox.launch.assert_called_once_with(
            headless=True, args=scraper._FIREFOX_LAUNCH_ARGS
        )
        mock_p.chromium.launch.assert_not_called()

    def test_firefox_launch_args_is_empty(self):
        assert scraper._FIREFOX_LAUNCH_ARGS == []

    def test_chromium_launch_args_not_passed_to_firefox(self, monkeypatch):
        monkeypatch.setattr(scraper, "_read_browser_engine", lambda: "firefox")
        mock_p = MagicMock()
        scraper._launch_browser(mock_p)
        call_kwargs = mock_p.firefox.launch.call_args
        assert "--no-sandbox" not in call_kwargs.kwargs.get("args", [])
```

## State Management Strategy

No new persistent state beyond `.playwright_browser` (a plain text file containing
`chromium` or `firefox`). Env var `PLAYWRIGHT_BROWSER` overrides it at runtime.
Neither is stored in the DB (`database.py`) or Streamlit session state — they are
infrastructure-level configuration consumed only at scraper startup.

## Risks and Edge Cases

| Risk | Mitigation |
|------|-----------|
| `playwright install firefox` also fails (rare, but possible if glibc too old) | `setup.sh` errors with clear message if both fail |
| User runs `scraper.py` without running `setup.sh` first (no marker file) | `_read_browser_engine()` defaults to `"chromium"` — same as current behavior |
| `.playwright_browser` file contains trailing newline or uppercase | `.strip().lower()` in `_read_browser_engine()` handles this |
| Existing tests mock `p.chromium.launch` directly instead of `_launch_browser` | Step 3c identifies and patches those tests |
| `playwright_stealth` v2 and Firefox: stealth context APIs differ slightly | `Stealth().apply_stealth_sync(ctx)` is browser-agnostic in v2 — no change needed |
| `_USER_AGENT` is a Chrome UA string but Firefox is the runtime | Google Maps serves content based on UA header, not browser engine. Chrome UA via Firefox is a legitimate stealth technique and is already the pattern used by this scraper. |
| `.playwright_browser` committed to git | Add to `.gitignore` — it is machine-local state |
